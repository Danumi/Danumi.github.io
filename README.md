# danumi.github.io

Öffentliche Hilfsseiten für die private Finanzapp.

- `finanzapp/callback` – nach der Bank-Freigabe bei Enable Banking leitet diese Seite zurück in die App. Sie enthält und speichert keine Finanzdaten.
- `.well-known/assetlinks.json` – bestätigt Android, dass Links auf `danumi.github.io/finanzapp/callback` direkt die Finanzapp öffnen dürfen.
